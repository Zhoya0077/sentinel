Sentinel — wallet approval security agent

Paste any EVM address. Sentinel finds its live ERC-20 approvals, scores each one's risk from on-chain facts, and generates the exact calldata to revoke the risky ones.

READ-ONLY — never signs, never broadcasts No wallet connection No keys, no sign-in Runs entirely in your browser
Enter a valid 0x address (40 hex characters).

Log discovery covers the chosen recent window; the known-spender sweep additionally checks curated major tokens against verified protocol contracts, so older approvals to known protocols still surface. Full-history discovery needs an indexer — see the write-up.

How to use a revoke calldata

  1. Read the decode under the calldata: it must say the spender and the amount exactly 0.
  2. In your own wallet, open the token contract's approve function (contract interaction / write contract) and paste the calldata — or use your wallet's revoke flow with the same spender and amount 0.
  3. Before signing, verify: the to address is the token contract, the spender matches, the amount is exactly 0, and you are on the expected network.
  4. Revoking sets that spender's allowance to 0. It does not move any tokens.

Sentinel never asks you to connect a wallet here. If a page claiming to be Sentinel asks for a key, a seed phrase, or a signature, it is not Sentinel.
